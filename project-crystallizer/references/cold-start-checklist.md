# Cold-Start Checklist

Review only the repository and its durable documents. Do not rely on the prior
conversation or the author's private memory.

- [ ] Can a fresh agent state what the project is?
- [ ] Can it distinguish Vision from Current Burst?
- [ ] Can it name the crystallizable unit?
- [ ] Can it identify what works, is partial, broken, and unknown?
- [ ] Can it find setup, run, test, and benchmark commands?
- [ ] Can it identify expected outputs and data/checkpoint locations?
- [ ] Can it see negative findings and rejected directions?
- [ ] Can it explain why work stopped here?
- [ ] Can it find the FUTURE parking lot?
- [ ] Can it follow the first 1-3 restart actions?
